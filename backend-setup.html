Sign in to the shared backend

Connected to the same backend as the ND dashboard. No database URL or API key to enter.

New account? Use a password of 12–128 characters. Verify using the email link, then return here to sign in. Already have an ND account? No second signup is needed.

Passwords are not stored. Access/refresh tokens stay in trusted extension-session storage, not in content scripts or persistent local storage. Browser restart or extension reload requires sign-in again; the queue remains on disk.
