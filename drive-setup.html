Deploy once

Paste the web-app URL

  1. Save the script, return to the Sheet, and refresh it. Choose Fudge → Set OpenAI API key and paste your new key.
  2. Select fudgeInstallAutomation beside Run.
  3. Click Run, then review and allow Google’s permissions once. This one approval is what lets Fudge keep the Sheet’s rephrasing triggers installed by itself from now on.
  4. Click Deploy → New deployment → Web app.
  5. Choose Execute as: Me, access Anyone, then deploy.

Already connected? Replace all the old code with the copy above, then run fudgeInstallAutomation once and approve access. Then choose Deploy → Manage deployments → ✏️ → Version: New version → Deploy. The /exec URL stays the same, so you will not need to paste it again.

For a new Sheet, use the deployed URL ending in /exec. To share a Sheet that is already connected somewhere else, paste its connection code, not its URL: every installation of Fudge invents its own secret, so the URL on its own is always rejected. On the connected computer open Change sheet → Copy connection code and paste the FUDGE1| code here. That deployment must also be set to Who has access: Anyone, or Google answers 404 for everyone except its owner.

The Apps Script edit trigger rephrases reviews entered in Structure → Review into Rephrased Content. It uses that row's Numbers cell for the phone number and continues working when Fudge is not installed.
